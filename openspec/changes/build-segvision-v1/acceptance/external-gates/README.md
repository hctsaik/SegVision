# External gates

These pending manifests are explicit fail-closed inputs, not approvals. An AI agent may verify technical facts and hashes, but it must not change an organizational approval, data provenance, human-review, or release-signoff field to `approved` without attributable external evidence.

- `model-artifact-manifest.pending.json`: pinned MobileSAM source and independently streamed checkpoint SHA-256; code and weights remain separately pending for redistribution authority.
- `reference-targets.pending.json`: separate physical performance and clean-install targets.
- `domain-inputs.pending.json`: attributable annotation-policy approval, representative images, independent gold, real annotator sessions, independent reviews, data authority, and release signoff.
